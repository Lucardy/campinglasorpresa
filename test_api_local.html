🧪 Test API Local - Camping La Sorpresa

Este archivo te permite probar la API de hospedajes en tu entorno local de XAMPP.

📋 Información del Entorno

URL de la API: http://localhost/campinglasorpresa/api/endpoints/hospedajes.php

Ubicación esperada: C:\xampp\htdocs\campinglasorpresa\api\

Puerto XAMPP: 80 (http://localhost)

🔗 Test 1: Conexión Básica

Prueba la conexión básica a la API

📊 Test 2: Obtener Tipos de Hospedaje

Prueba obtener los tipos de hospedaje y hospedajes

🔍 Test 3: Verificar Estructura de Respuesta

Verifica que la respuesta tenga la estructura correcta

🚨 Test 4: Manejo de Errores

Prueba el manejo de errores con una URL incorrecta

📝 Instrucciones para Solucionar Problemas

  1. Verifica que XAMPP esté corriendo - Apache debe estar activo
  2. Verifica la ruta de archivos - Los archivos deben estar en C:\xampp\htdocs\campinglasorpresa\api\
  3. Verifica permisos - Los archivos PHP deben ser legibles
  4. Verifica la base de datos - MySQL debe estar corriendo y accesible
  5. Revisa los logs de XAMPP - Busca errores en Apache y MySQL

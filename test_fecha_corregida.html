📋 Problema Identificado y Solucionado

Problema: Las fechas se corrompían y se enviaban como "20205-09-04" (con un "5" extra)

Solución: Se agregó validación de fechas antes de enviar a la API

Mejoras:

  • ✅ Validación de formato de fecha (YYYY-MM-DD)
  • ✅ Validación de fecha válida
  • ✅ Validación de fechas futuras
  • ✅ Validación de fechas no muy lejanas (máximo 10 años)
  • ✅ Atributo `min` en campos de fecha
